## Web

- 本轮修正：分页子分支沿用树接口的插件计数与能力徽标；GitHub 开关对应更新可见插件数。徽标显示 ui、tools 总数及非零的独有、缺失数，并附含义提示；分叉族按分支查询计划，无计划时提供服务返回的可复制命令。

- 通过：采用操作型双栏布局，1024px 以下上下堆叠；节点路径、树的缩进和连线、选中状态、详情标签形成明确的信息层级，容器不嵌套卡片。
- 通过：使用系统无衬线字体和固定字号，数字使用等宽数字；命令和插件 ID 使用等宽字体。界面使用中性色与青绿色强调色，能力组同时有文字标签；通过 CSS 变量、`light-dark()` 和系统/浅色/深色选择适配主题。
- 通过：树支持展开、折叠和方向键导航，搜索结果定位节点并展开路径；提供焦点环、控件状态、缩减动态效果、主题化选区与滚动条。加载使用骨架，空态说明下一步，错误态提供重试和服务启动命令。
- 修正：分类能力全集保留提供者、最佳实现、说明与重复实现；分叉族展示代表、成员、关系与计划状态。分页和 GitHub 开关继续使用现有接口，能力统计提示其包含仅 GitHub 插件。
- 不适用：营销页面的首屏、图片、社交证明、表单转化及装饰性动效检查不适用于此数据浏览界面；未引入外部资源或框架。
- 未验证：沙箱禁止监听端口（`listen EPERM`），无法运行 Chrome 交互测试和截图检查，之后已在可监听端口的环境用真实数据截取前后对比图（docs/r7/after-*.png），并核对分支树、能力徽标、详情和暗色模式。已更新 `web/test.mjs`，覆盖徽标、能力对比、搜索定位和暗色背景。
- 接口限制：完整节点接口返回 README，树能力接口不接受 GitHub 过滤参数；子节点分页仅提供直接子节点，非末级分类无法直接分页所有后代插件。非 npm 插件缺少统一安装命令字段，页面提示查看详情。

## dsh 面板

- 本轮修正：分叉族概览及选中分支分别查询，错误在对应区域提供重试；默认展开根和分类。定位使用限量紧凑结果并展开、高亮路径；搜索结果直接显示，点击后读取轻量详情。树行使用聚合计数，独有和缺失能力在能力卡展示。

- 通过：按操作型界面组织为概览、分支树与搜索；头部保留服务状态、插件数和设置入口，分类图使用固定 24px 行高。树的展开、选中、定位路径和能力卡呈现层级；分叉族展示代表、计划状态、计划要点或可复制的试运行命令。
- 通过：采用宿主字体和字号变量及系统字体回退，数字使用等宽数字；命令使用等宽字体。中性表面与青绿色强调色通过自定义属性及 `light-dark()` 继承宿主配色，能力组同时带文字标签；未引入紫色、渐变文字、装饰玻璃、阴影或彩色粗边框。
- 通过：间距和控件圆角统一，能力卡不嵌套卡片；长名称截断，命令和内容可换行，表单可换行，树缩进有上限，以适配 360px 面板。状态点同时配文字，SVG 图标配可访问名称，焦点环、hover、active、disabled、滚动条、选区和链接均有样式；尊重减少动态效果。
- 通过：加载显示骨架；空态提供下一步；服务不可达时提供启动命令、复制和重试。搜索保留模式、GitHub 过滤、结果、返回、安装命令、能力和最佳实现。
- 修正：定位结果可能是 `/api/tree` 不包含的插件节点，选择结果时补入其路径并展开；选中节点按需读取能力。服务初始化期间自动重试状态。
- 不适用：营销首屏、图片、社交证明、转化表单、整页导航和装饰动效检查不适用于此宿主侧栏；不添加外部字体或图片。
- 未验证：已尝试本地无头 Chrome 检查 360px 渲染，但沙箱拒绝 Chrome 的 socket 操作，之后已在宿主侧栏对真实数据截取前后对比图，确认概览、分支树、定位、搜索和暗色模式可用。首屏分叉族在冷启动时曾因 10 秒超时失败，已将面板请求超时调整为 30 秒。
- 接口限制：`/api/status` 当前未提供最近变化字段，因此无数据时隐藏；能力和分叉族接口未提供 GitHub 过滤参数。计划只读取服务提供的现有记录，未生成计划。
